# python-nauka

Moje pierwsze projekty w Pythonie. 

Tutaj tworzę proste rzeczy pod naukę tego języka.

## Jakie projekty tu są:

- **kalkulator.py**: prosty kalkulator konsolowy który liczy dodawanie, odejmowanie, mnożenie, dzielenie, potęgi (kwadratowe), pierwiastki oraz silnię.

- **zgadnij_liczbe.py**: prosta gra polegająca na odgadnięciu liczby. Gra ma 3 poziomy trudności: łatwy od 1-10, średni od 1-100, trudny od 1-1000. Liczy też ile razy wygrałeś lub przegrałeś.

- **listy.py**: konsolowy menedżer zadań, który: dodaje, wyświetla i usuwa zadania po numerze oraz po wpisaniu zadania. Dane zapisują się do pliku JSON.

## Czego się nauczyłem z tych projektów:

Pętli, warunków, list, funkcji, obsługi błędów (`try/except`), pracy z plikami JSON.

## Jak uruchomić dany projekt?

W terminalu (z Windows Terminal, edytora kodu Visual Studio Code, PyCharm):

    python nazwa_pliku.py

Na przykład:

    python zgadnij_liczbe.py
